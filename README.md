# Teachable AI for micro:bit (블루투스 버전)

티처블머신(Teachable Machine) 이미지 분류 모델을 마이크로비트 MakeCode 블록으로 쓰는 확장입니다.
카메라와 AI는 컴퓨터의 웹페이지(짝꿍 페이지)가 맡고, 분류 결과는 **블루투스**로 마이크로비트에 전달됩니다.
USB는 MakeCode에 계속 연결해 둘 수 있습니다.

> **마이크로비트 V2 전용**입니다. (V1은 메모리가 부족해 블루투스와 함께 쓸 수 없습니다.)

## 블록

- `AI 모델 주소 [URL] 설정하기`
- `AI 연결 시작하기`
- `AI가 [클래스] 을(를) 인식했을 때` (이벤트)
- `AI 인식 결과`
- `AI 인식 확률` (0–100)
- `AI가 [클래스] 을(를) 인식했는가`
- `AI가 [클래스] 이고 확률이 [80] 이상인가`
- `AI가 연결되어 있는가`

## 사용 순서

1. 티처블머신에서 이미지 모델을 학습하고 **모델 내보내기 → 모델 업로드**로 공유 링크를 받습니다.
2. MakeCode(makecode.microbit.org)에서 새 프로젝트를 만들고 **확장** 검색창에 이 저장소 주소를 붙여 넣습니다.
3. **톱니바퀴 → 프로젝트 설정**에서 블루투스 페어링을 **'페어링 필요 없음'(No Pairing Required)**으로 바꿉니다.
4. 블록을 짭니다.
   ```
   시작하면: AI 모델 주소 "https://teachablemachine.withgoogle.com/models/XXXX/" 설정하기
   AI가 "rock" 을(를) 인식했을 때: 아이콘 출력 ■
   AI가 "paper" 을(를) 인식했을 때: 아이콘 출력 ☺
   ```
5. 마이크로비트에 **다운로드**합니다. (USB는 꽂아 둔 채로 둡니다.)
6. 짝꿍 페이지를 데스크톱 크롬·엣지로 엽니다: `https://아이디.github.io/저장소이름/`
7. **블루투스로 연결** → 목록에서 `BBC micro:bit [...]`를 고릅니다. 모델 주소를 자동으로 받아옵니다.
8. **카메라 · AI 시작**을 누르면 마이크로비트가 반응합니다.

블록을 고쳐 다시 다운로드하면 블루투스 연결이 잠시 끊기고, 페이지가 자동으로 다시 연결을 시도합니다.

## 주의

- 클래스 이름은 **짧게**(영어 16자, 한글 5자 이내) 정하세요. 블루투스로 한 번에 받을 수 있는 양이 적습니다.
- 마이크로비트 LED는 한글을 표시하지 못합니다. 아이콘이나 영어 글자를 쓰세요.
- MakeCode의 가상 마이크로비트(시뮬레이터)는 반응하지 않고, 실제 마이크로비트만 반응합니다.
- 블루투스를 켠 프로젝트에서는 `무선(radio)` 블록을 같이 쓸 수 없습니다.

## 통신 규칙

블루투스 UART 서비스, 한 줄씩(끝은 `\n`).

- 페이지 → 마이크로비트: `HELLO`
- 마이크로비트 → 페이지: `TMURL|https://teachablemachine.withgoogle.com/models/XXXX/`
- 페이지 → 마이크로비트: `TMPRED|클래스이름|0.973`
