마이크로비트 연결 안 됨
이 브라우저는 마이크로비트 USB 연결(Web Serial)을 지원하지 않아요. 크롬, 엣지, 웨일 브라우저로 열어 주세요. (아이패드·휴대폰은 사용할 수 없어요)

1마이크로비트 연결

메이크코드에서 다운로드한 뒤, 메이크코드의 연결을 끊고 눌러 주세요.

2모델 불러오기

마이크로비트 블록에 넣은 모델 주소가 있으면 연결할 때 자동으로 불러와요.

3카메라

모델을 불러오면 카메라가 켜져요

이 화면이 모델이 보는 그대로예요. 영상은 이 컴퓨터 안에서만 쓰이고 밖으로 보내지 않아요.

  • 연결이 안 되면: 메이크코드 화면에서 연결을 끊었는지, 다른 탭에서 마이크로비트를 쓰고 있지 않은지 확인하세요.
  • 응답이 없으면: tm_microbit 확장 블록이 들어간 코드를 다운로드했는지 확인하세요.
  • 모델이 안 열리면: 티처블머신에서 [모델 내보내기 → 업로드]를 눌러 받은 링크인지 확인하세요.
  • 클래스 이름은 영어로 지으면 LED에도 표시할 수 있어요. 블록에는 대소문자까지 똑같이 적어야 해요.
