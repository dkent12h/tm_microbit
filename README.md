# 티처블머신 × 마이크로비트 (tm_microbit)

티처블머신으로 만든 이미지 모델을 마이크로비트 메이크코드 블록으로 쓰는 확장입니다. 엔트리 인공지능 블록처럼 `분류 결과가 ~일 때`, `~의 신뢰도` 같은 블록을 제공합니다.

카메라와 모델 추론은 웹앱이 맡고, 마이크로비트는 USB 케이블로 결과를 받습니다. 영상은 컴퓨터 밖으로 나가지 않습니다.

- 웹앱: https://dkent12h.github.io/tm_microbit/
- 지원 브라우저: 크롬, 엣지, 웨일 (아이패드·휴대폰 불가)
- 지원 보드: micro:bit V1, V2

## 확장으로 추가하기

1. https://makecode.microbit.org 에서 새 프로젝트를 엽니다.
2. 블록 목록에서 **확장**을 누릅니다.
3. 검색창에 `https://github.com/dkent12h/tm_microbit` 를 붙여 넣고 고릅니다.

## 수업에서 쓰는 순서

1. **티처블머신**에서 이미지 프로젝트를 만들고 학습합니다. 클래스 이름은 영어로 짓습니다(예: rock, paper, scissors).
2. **모델 내보내기 → 업로드**를 누르고 공유 링크를 복사합니다.
3. **메이크코드**에서 `시작하면` 안에 `티처블머신 모델 주소 ( ) 로 정하기`를 넣고 링크를 붙여 넣습니다.
4. `분류 결과가 ( ) 일 때` 블록으로 동작을 만듭니다.
5. 마이크로비트에 **다운로드**한 뒤, 메이크코드의 **연결을 끊습니다**. (연결된 채로 두면 웹앱이 포트를 열 수 없습니다)
6. **웹앱**을 열고 `연결하기` → 마이크로비트 선택. 모델이 자동으로 불러와지고 카메라가 켜집니다.

## 블록

| 블록 | 설명 |
|---|---|
| 티처블머신 모델 주소 ( ) 로 정하기 | 시작하면 안에 넣습니다. 웹앱이 이 모델을 자동으로 불러옵니다. |
| 분류 시작하기 / 분류 멈추기 | 처음에는 시작된 상태입니다. |
| 분류 결과가 ( ) 일 때 | 결과가 그 클래스로 **바뀔 때** 한 번 실행됩니다. |
| 분류 결과 | 지금 결과(클래스 이름). 없으면 빈 글자. |
| 분류 결과가 ( ) 인가? | 참/거짓 |
| 분류 결과의 신뢰도 | 0~100 |
| ( ) 의 신뢰도 | 클래스 하나의 신뢰도, 0~100 |
| 분류 결과 번호 | 첫 클래스가 0. 없으면 -1. |
| 신뢰도 기준을 ( ) 으로 정하기 | 기준보다 낮으면 결과를 무시합니다. |
| 웹앱과 연결되었을 때 / 웹앱과 연결되었는가? | 연결 확인 |

## 예제 (가위바위보)

```blocks
tm.onConnected(function () {
    basic.showIcon(IconNames.Yes)
})
tm.onLabel("rock", function () {
    basic.showIcon(IconNames.SmallSquare)
})
tm.onLabel("paper", function () {
    basic.showIcon(IconNames.Square)
})
tm.onLabel("scissors", function () {
    basic.showIcon(IconNames.Scissors)
})
tm.setModel("https://teachablemachine.withgoogle.com/models/모델ID/")
tm.setThreshold(70)
```

## 주의할 점

- 클래스 이름은 블록에 **대소문자까지 똑같이** 적어야 합니다.
- 한글 클래스 이름은 비교는 되지만 LED에 표시할 수 없습니다. 번호 블록을 쓰면 편합니다.
- 이 확장은 시리얼(USB) 통신을 씁니다. 같은 코드에서 시리얼 블록을 따로 쓰면 충돌할 수 있습니다.
- 메이크코드 시뮬레이터로는 결과를 받을 수 없습니다. 실제 보드로 확인하세요.
- 지금은 이미지 모델만 지원합니다.

## 통신 규칙 (개발용)

한 줄씩, 줄바꿈으로 끝납니다. USB 시리얼 115200bps.

| 방향 | 메시지 | 의미 |
|---|---|---|
| 웹앱 → 보드 | `H` | 연결 확인 |
| 웹앱 → 보드 | `L\|rock,paper,scissors` | 클래스 목록 |
| 웹앱 → 보드 | `R\|0\|rock\|92\|92,5,3` | 번호, 이름, 신뢰도, 전체 신뢰도 |
| 보드 → 웹앱 | `M\|모델ID` | 모델 알림 |
| 보드 → 웹앱 | `S` / `P` | 분류 시작 / 멈춤 |
